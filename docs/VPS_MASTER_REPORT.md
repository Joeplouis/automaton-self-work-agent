## Safety / Change-Control Rules

- Never print or copy secrets into reports, prompts, logs, Git commits, or child-agent messages.
- Never expose wallet private keys.
- Never mount or expose the host Docker socket to an untrusted containerized worker.
- Back up configuration/state before consequential modification.
- Prefer reversible changes.
- Verify repository dirty state before editing code.
- Do not destroy or replace an existing system merely because rebuilding appears easier.
- Do not make irreversible financial transfers without respecting configured treasury policy and creator oversight.
